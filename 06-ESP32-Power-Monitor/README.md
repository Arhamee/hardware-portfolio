# 4-Layer Power Monitoring System

ESP32-based power monitoring and control system with a web dashboard.

**Status:** Design complete

## Hardware
- ESP32 microcontroller
- 5-channel relay module for device control
- Precision current sensor per channel
- Voltage monitoring circuitry
- 4-layer PCB with proper power planes

## Software
Web dashboard with real-time power consumption monitoring, individual ON/OFF
device control, historical usage bar graphs, and responsive dark-theme UI.
