# General-Purpose IoT Board — ESP32-WROOM

4-layer board built around the ESP32-WROOM module as a versatile, expandable
IoT development platform.

## Features
- **Si7021** — I²C temperature and humidity sensor
- **QWIIC connector** — plug-and-play expansion for other I²C devices
- **CP2104** — USB-to-serial UART with onboard programmer, no external
  programmer needed
- **RGB LED + button** — status indication and user input
- **Screw terminals** — LED strip interface, 4-level converted outputs,
  fused power supply
- **Power relay** — control for high-power devices (lights, motors, appliances)

## Why 4 layers
Cleaner routing and better signal integrity for the ESP32's high-speed
requirements, especially with multiple peripherals sharing the board.
