# DeskBuddy v2

Custom PCB replacing a breadboard prototype's separate modules with a
single integrated board.

## What Got Replaced
- Separate charging module → **IP5306** (charges, protects, and boosts to 5V — one chip)
- Standalone touch sensor breakout → **TTP223** etched directly onto the board
- Breakout boards and jumper wires → clean, compact PCB

## Features
- ESP32-C3 + OLED display
- Live battery indicator on-screen
- Animated eyes with expressions
- Real-time weather with custom icons
- Auto-syncing clock (timezone-aware)
- Birthday celebration mode

## Note
Started as "let me make my desk less boring" — turned into a full PCB
design exercise in component integration and board miniaturization.
