# IoT Control Board — ESP32-C3

Custom board combining power electronics and embedded IoT into one design,
plus a companion programming board.

## Power Path
12V input → boost converter → 5V → 3.3V regulation for the ESP32-C3

## Features
- Handles up to 5A load
- Onboard fuse protection
- Integrated T90 relay for high-power switching
- Dashboard integration (QWIN AI) for real-time monitoring and control

## Bonus
A separate USB-to-UART programming board, built alongside this one, for
seamless firmware uploading and debugging.

## What This Covered
End-to-end IoT product design — power management, protection, communication,
and control — not just the MCU layout.
