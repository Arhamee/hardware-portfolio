# IoT Dev Board — ESP32-S3 (8MB Flash)

4-layer board built for speed and scalability in IoT/edge projects.

## Features
- ESP32-S3, 8MB flash
- Si7021 temperature/humidity sensor
- USB-C for power and programming
- QWIIC and SPI expansion headers
- BOOT/RESET buttons, RGB LED status

## Stackup
Clean 4-layer design balancing signal integrity and thermal efficiency —
intended as a reusable base for future sensor/edge-device projects.
